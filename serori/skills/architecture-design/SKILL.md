# Architecture design

Do not design from article claims alone. Define interfaces, state machines, thread priorities,
context legality, ownership transfer/release, queue-full policy, timeout/retry behavior, backend
failure policy, stop/drain/restart, and memory/latency budgets. Emit an architecture record with
decisions, alternatives, risks, evidence, and required tests. Status remains draft until reviewed.
